# Scans

The sources for the IBM Selectric revivals. The image files are not in the repository; put them in this
directory under these names.

| Files | What they are | Used for |
|---|---|---|
| `selectric-a-0000.jp2` … `-0011.jp2` | "IBM Selectric Typewriter Type Styles" (1972), [archive.org ibm-selectric-typewriter-type-styles](https://archive.org/details/ibm-selectric-typewriter-type-styles) (the `_jp2.zip`, pages renamed `selectric-a-<page>.jp2`) | Pages 3, 4 and 6: the 20 text faces |
| `selectric-b-0000.jp2` … `-0007.jp2` | "IBM Selectric Typewriter Type Styles" (about 1970), [archive.org ibm-selectric-typewriter-type-styles-1970](https://archive.org/details/ibm-selectric-typewriter-type-styles-1970) | Not used yet: a second sample of most faces, and the faces' code numbers |
| `selectric-c-0000.jp2` … `-0007.jp2` | The same brochure as a, a later printing, [archive.org ibm-selectric-typewriter-type-styles-brochure](https://archive.org/details/ibm-selectric-typewriter-type-styles-brochure) | Not used yet: a second sample of every face |

The scans are about 600 dpi; the reader measures each page's pitch in pixels (60.0–60.3 px for 10 pitch,
50.1–50.3 px for 12).
