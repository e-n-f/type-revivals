# Scans

The fonts are traced from eight photographs of D. Stempel AG *Schriftmuster-Karteikarten*
(specimen cards after DIN 16517) in the Letterform Archive's Flickr album
<https://www.flickr.com/photos/letterformarchive/albums/72177720310834741/>.
They are not in the repository; download the originals ("Original" size, about 9900 × 7000 px)
into this directory under these names:

| File | Card | Used for |
|---|---|---|
| `53152153329_ccac30d200_o.jpg` | Palatino, St. 2, character sheet | Regular glyphs |
| `53151949716_f2b68c5eb6_o.jpg` | Palatino, St. 2, sizes 5–48 p | Regular spacing |
| `53151948621_96e2d43e53_o.jpg` | Palatino-Kursiv, St. 43, character sheet | Italic glyphs |
| `53151374322_e5932bda02_o.jpg` | Palatino-Kursiv, St. 43, sizes 5–48 p | Italic spacing |
| `53152378370_1a1b225d3d_o.jpg` | Palatino-Kursiv-Schwungversalien, St. 94, character sheet | Italic swash capitals |
| `53152150304_27da1719ee_o.jpg` | Palatino-Kursiv-Schwungversalien, St. 94, sizes 6–48 p | Swash capitals' spacing |
| `53152152234_df7303667c_o.jpg` | Halbfette Palatino, St. 44, character sheet | Bold glyphs |
| `53151948591_7b952d8a3e_o.jpg` | Halbfette Palatino, St. 44, sizes 6–48 p | Bold spacing |

Each file name starts with the photo's Flickr ID: `https://www.flickr.com/photos/letterformarchive/<ID>/`.
